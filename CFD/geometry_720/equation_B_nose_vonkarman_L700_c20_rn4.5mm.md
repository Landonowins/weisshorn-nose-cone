# Weisshorn nose cone, study B: Von Karman 700 + 20 mm

x is measured along the axis from the blunted tip, r is the outer radius (mm).

| Part | Range of x | r(x) |
|---|---|---|
| Spherical tip | 0 to 2.905 | r = sqrt(r_n^2 - (r_n - x)^2), r_n = 4.500 |
| Haack profile | 2.905 to 694.600 | r = R/sqrt(pi) * sqrt(theta - sin(2 theta)/2 + C sin^3(theta)), theta = arccos(1 - 2 (x + delta)/L) |
| Coupler cylinder | 694.600 to 714.600 | r = R |

| Parameter | Value |

| Curved part, blunted tip to shoulder | 694.600 mm |
