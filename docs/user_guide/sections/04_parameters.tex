\section{The Configuration File}
\label{sec:parameters}

\subsection{How the file works}

A study is one YAML file (\texttt{configs/weisshorn.yaml} is the complete, commented example): \emph{sections}
contain \texttt{name: value} lines indented by two spaces, lists are \texttt{[a, b, c]}, \texttt{\#} starts a comment.
\begin{itemize}[leftmargin=*,itemsep=1pt]
\item \textbf{Only what differs from the default is needed}; \textbf{units are SI} (lengths in metres:
\texttt{diameter: 0.180}, not \texttt{180}); relative paths are relative to the file.
\item \textbf{Inheritance}: \texttt{base: weisshorn.yaml} takes every value of that file and overrides only what is
listed; a list replaces the inherited list.
\item \textbf{Checking}: \texttt{python -m nosecone validate my.yaml} stops at the first problem with a precise
message (e.g.\ \texttt{unknown parameter 'nose.profils' (did you mean 'profiles'?)}); \texttt{-{}-show} prints every
value used. The run saves them as \texttt{config\_used.yaml}.
\item \textbf{All parameters}: \texttt{python -m nosecone describe-config} lists every parameter with unit, valid
range and default (\texttt{-{}-basic} hides the advanced numerical settings).
\end{itemize}

\subsection{Structured parameters}
\label{sec:structured}

\paragraph{Profiles.} Built-in: \texttt{cone}, \texttt{ogive}, \texttt{parabolic}, \texttt{power050},
\texttt{power075}, \texttt{lvhaack}, \texttt{vonkarman}. Other members of a family (\texttt{python -m nosecone
profiles} lists them) go in \key{nose.custom\_profiles}:
\begin{lstlisting}[language=yaml]
nose:
  custom_profiles:
    power060: {family: power, n: 0.6, label: "Power $n=0.6$"}
  profiles: [vonkarman, power060]
\end{lstlisting}
A custom profile has no CFD data until it is computed (\key{aerodynamics.compute\_missing: true}).

\paragraph{Robustness scenarios.} A name plus changes to the nominal model (\texttt{transonic\_onset},
\texttt{transonic\_factor}, \texttt{drag\_factor\_scale}, \texttt{mass\_model}, \texttt{ground\_temperature}):
\begin{lstlisting}[language=yaml]
robustness:
  scenarios:
    - {name: nominal}
    - {name: "transonic peak +20 %", transonic_factor: 1.2}
\end{lstlisting}

\paragraph{Decision matrix.} \key{trade\_matrix.weights} (e.g.\ \texttt{\{performance: 4, integration: 2,
manufacture: 2, stability: 1\}}) are normalised to sum to one; \key{manufacture} scores are your judgement, the
others are computed.

\paragraph{CFD studies.} \key{cfd.studies}: a list of \texttt{\{name, profiles, fineness, machs\}} (optional
\texttt{tip\_radius\_ratios}, \texttt{grid}, \texttt{max\_iter}); see Section~\ref{sec:newcfd}.
