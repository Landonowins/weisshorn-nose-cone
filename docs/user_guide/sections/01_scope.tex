\section{What the Tool Does, and What It Does Not}
\label{sec:scope}

The \texttt{nosecone} package compares nose cones for a supersonic sounding rocket (\emph{profile}, \emph{fineness}
$L/D$ and \emph{tip radius}) and exports the CAD geometry of the selected one. It reproduces
2027\_C\_FD\_REPORT-1\_NOSE-CONE exactly, but every vehicle-specific number is an input, so it serves any ERT
rocket.

\paragraph{Computed for every nose} (profile $\times$ fineness $\times$ tip radius): geometry (volume, wetted area,
shoulder angle, Barrowman CP, payload room), wave drag $C_{D,\rm w}(M)$ from the CFD database, apogee of the full
vehicle, nose mass and static-margin change against a baseline nose. \textbf{For the study}: apogee sensitivities,
robustness of the ranking, cost of a blunt tip, tip and shell temperatures, a decision matrix and the CAD files.

\paragraph{Limits.}
\begin{itemize}[leftmargin=*,itemsep=1pt]
\item \textbf{Wave drag}: inviscid Euler CFD at zero incidence, tabulated at $M = 1.1$--1.6 and $L/D = 2.5$--5
for the sweep profiles; held constant outside. Below $M = 1.1$ an assumed transonic ramp (the weakest part; replace with RANS data).
\item \textbf{Rest of the vehicle}: empirical drag build-up scaled by one factor $k$, calibrated on a known apogee.
\item \textbf{Trajectory}: 2D point mass, ISA below \SI{11}{km}, no wind. \textbf{Stability}: Barrowman, use for
\emph{changes} of static margin only.
\item \textbf{Not done}: structure, viscous or transonic CFD, angle of attack, 6-DOF flight, shape optimisation.
A profile without CFD data is skipped unless \key{aerodynamics.compute\_missing} is true.
\end{itemize}
\texttt{tests/verify\_reference.py} checks that the Weisshorn results are still reproduced
(Appendix~\ref{app:verification}); run it after any code change.
