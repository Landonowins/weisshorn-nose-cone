\section{Data tables for ST}
\label{app:data}

Six CSV files in \file{report_720/data/}, one set per design (\texttt{A\_}, \texttt{B\_}), written by
\file{report_720/figures.py}. $x$ is measured from the blunted tip along the axis; pressures are absolute;
$\Delta p > 0$ pushes the shell inwards. Between $x = 3$ and \SI{15}{mm} the Fluent values are smoothed
over \SI{2}{mm}.
