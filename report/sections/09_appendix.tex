\section{Scripts and data}
\label{app:scripts}

{\sloppy The study is the Python package \texttt{nosecone} in the repository
\url{github.com/Landonowins/weisshorn-nose-cone} (private; ask the author for access).\par}
\begin{verbatim}
python -m nosecone run configs/weisshorn.yaml
\end{verbatim}
reproduces every number, table, figure and CAD file of this report from the Euler database
(\texttt{data/euler\_results.csv}, \texttt{data/cfd/}); \texttt{tests/verify\_reference.py} checks it, and
the user guide (2027\_C\_FD\_REPORT-3) explains how to apply the tool to another vehicle.
